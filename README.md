# Lunar-Ledger-Analytics
A Python personal finance analysis project exploring transaction trends, spending categories, and monthly patterns.

# Personal Finance EDA

## Overview
This project analyzes a personal finance dataset containing transaction records with details such as date, description, amount, transaction type, category, account name, and month.

I built this project to practice exploratory data analysis in Python and to better understand spending patterns, income flow, and monthly transaction behavior.

## Dataset
The dataset contains 806 transaction records and 7 columns:
- Date
- Description
- Amount
- Transaction Type
- Category
- Account Name
- Month

## Tools Used
- Python
- pandas
- matplotlib
- seaborn
- VS Code

## Analysis Performed
- Loaded and inspected the dataset.
- Checked for missing values and duplicate rows.
- Counted transaction types and categories.
- Summed amounts by category and transaction type.
- Analyzed monthly totals.
- Reviewed the distribution of transaction amounts.

## Key Findings
- The dataset is complete and has no missing values in the main columns.
- Some categories appear more frequently than others.
- Credit and debit transactions show different total amounts.
- Monthly totals help reveal changes in financial activity over time.

## What I Learned
This project helped me become more comfortable with pandas groupby operations, sorting, and data visualization. It also gave me more practice working with real-world financial data.

## Limitations
This analysis is based on one sample financial dataset, so the results may not represent all spending habits. The project is also limited to the columns provided in the file.
